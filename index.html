Service Models Documentation

Comprehensive technical guide for multi-tenant service booking systems

📋 Overview

These models represent a multi-tenant service booking system for a business platform. Think of it like platforms such as Uber, Airbnb, or TaskRabbit where businesses offer services at different locations and customers can book them.

1

ServiceType Model

What It Is

A category or classification of services that a business offers.

Real-World Example

Imagine a company called "BeautyPro" that offers beauty services:

ServiceType 1: Hair Services
ServiceType 2: Makeup Services
ServiceType 3: Nail Services

Key Properties Explained

ServiceTypeId = 1 TypeName = "Hair Services" Description = "Professional hair cutting, coloring, and styling services" CompanyBusinessId = 5 (BeautyPro's business ID) CreatedDate = Jan 1, 2024 IsActive = true

Why It Matters

Categorization
Navigation
Reporting

Helps organize what types of services a business offers, allowing customers to browse by service type and businesses to analyze revenue by category.

Relationships

  • One ServiceType has many Services (Hair cutting, hair coloring, hair styling are all Hair Services)
2

Service Model

What It Is

A specific service offering under a ServiceType.

Real-World Example

Under the "Hair Services" ServiceType, BeautyPro offers:

Service 1: Basic Haircut - $25
Service 2: Hair Coloring - $75
Service 3: Hair Styling - $50

Key Properties Explained

ServiceId = 101 Name = "Professional Hair Coloring" SecondaryName = "Full Color Treatment" Description = "Complete hair coloring with premium products" CurrentPrice = 75.00 ServiceTypeId = 1 (Hair Services) CompanyBusinessId = 5 (BeautyPro) IsActive = true

Important Notes About Structure

Multi-Level Pricing:

  • CurrentPrice in Service = General price across all locations
  • But each location can have a different price (see ServiceCompanyBusinessLocation)

Example: BeautyPro Downtown charges $75 for hair coloring, while BeautyPro Mall location charges $85 for the same service.

Relationships

  • One Service belongs to one ServiceType
  • One Service belongs to one CompanyBusiness
  • One Service has many ServiceImages (before/after photos)
  • One Service has many ServiceCompanyBusinessLocations (available at multiple locations)
3

ServiceCompanyBusinessLocation Model

What It Is

A bridge table that links Services to specific business locations and defines location-specific pricing.

Real-World Example

BeautyPro operates in 3 locations:

Downtown Branch
Hair Coloring: $75
Shopping Mall Branch
Hair Coloring: $85
Airport Branch
Hair Coloring: $95 (Premium)

Example Configuration

ServiceCompanyBusinessLocationId = 1001 ServiceId = 101 (Hair Coloring) Name = "Hair Coloring - Downtown" ServicePrice = 75.00 CompanyBusinessLocationId = 10 (BeautyPro Downtown) IsActive = true

Why This Model Exists

Without this model, you'd have to create a separate Service record for each location, causing massive data duplication. This model elegantly solves that by letting one Service appear in many locations with different prices.

Relationships

  • One Service can have many ServiceCompanyBusinessLocations
  • One CompanyBusinessLocation can have many ServiceCompanyBusinessLocations
  • One ServiceCompanyBusinessLocation has many ServiceCompanyBusinessLocationBookings
  • One ServiceCompanyBusinessLocation has many ServiceCompanyBusinessLocationPriceHistories
  • One ServiceCompanyBusinessLocation has many ServiceCompanyBusinessLocationImages
  • One ServiceCompanyBusinessLocation has many ServiceCompanyBusinessLocationComments
4

ServiceCompanyBusinessLocationImage Model

What It Is

Photos/images specific to a service at a specific location.

Real-World Example - Hair Coloring at Downtown Location

Salon Interior
Before & After Example 1
Before & After Example 2

Why Separate From ServiceImage?

ServiceImage: Generic images of the service itself
ServiceCompanyBusinessLocationImage: Location-specific images

Relationships

  • One ServiceCompanyBusinessLocation has many ServiceCompanyBusinessLocationImages
5

ServiceCompanyBusinessLocationPriceHistory Model

What It Is

A record of all price changes for a service at a location over time.

Real-World Example - Hair Coloring Price Changes

Jan 1, 2024: $75.00 (original price) Apr 1, 2024: $80.00 (seasonal increase) Jul 1, 2024: $85.00 (summer premium) Oct 1, 2024: $80.00 (back to normal)

Why It's Important

Audit Trail
Analytics
Reporting
Compliance

Track why and when prices changed, see pricing trends, calculate revenue accurately using historical prices, and maintain compliance with regional requirements.

6

ServiceCompanyBusinessLocationBooking Model

What It Is

A customer's booking/reservation for a service at a specific location.

Real-World Example - Customer Booking

ServiceCompanyBusinessLocationBookingId = 2001 ServiceCompanyBusinessLocationId = 1001 (Hair Coloring - Downtown) CustomerId = 300 (John Doe) CustomerName = "John Doe" BookingDate = January 20, 2024 StartTime = 14:00 (2:00 PM) EndTime = 15:30 (3:30 PM) PaymentStatus = "Pending" BookingStatus = "Confirmed" StaffId = 50 (Assigned hair stylist)

Key Booking States

BookingStatus: Confirmed, Pending, Completed, Cancelled

PaymentStatus: Pending, Paid, Refunded, Failed

7

ServiceCompanyBusinessLocationComment Model

What It Is

Customer reviews/feedback and ratings for a service at a specific location.

Real-World Example - Customer Review

ServiceCompanyBusinessLocationCommentId = 3001 CustomerId = 300 (John Doe) ServiceCompanyBusinessLocationId = 1001 (Hair Coloring - Downtown) RatingId = 5 (5-star rating) CommentTitle = "Excellent Service!" Comment = "Maria did an amazing job. The color looks perfect and the service was friendly." CommentDate = January 20, 2024 IsActive = true

Why This Model

Social Proof
Quality Control
Improvement

Other customers see reviews before booking, business owners can see feedback on each service at each location, and identify which locations/services need improvement.

Relationships

  • One Customer has many ServiceCompanyBusinessLocationComments
  • One ServiceCompanyBusinessLocation has many ServiceCompanyBusinessLocationComments
  • One Rating has many ServiceCompanyBusinessLocationComments
8

Complete Data Flow - Real Booking Example

Scenario: Customer books Hair Coloring at BeautyPro Downtown

Step 1: Setup (Admin creates data)

1. Create ServiceType: "Hair Services"

2. Create Service: "Hair Coloring" ($75)

3. Create ServiceCompanyBusinessLocation: Links Hair Coloring to Downtown location with price $80

4. Create ServiceCompanyBusinessLocationImages: Upload before/after photos

5. Set price history when price changes

Step 2: Customer Searches

Customer sees:

• ServiceType: "Hair Services"

• Service: "Hair Coloring"

• Location: Downtown

• Price: $80 (from ServiceCompanyBusinessLocation)

• Images: Before/after photos

• Reviews: 4.8 stars

Step 3: Customer Books

Create ServiceCompanyBusinessLocationBooking:

• Date: Jan 20, 2024

• Time: 2:00 PM - 3:30 PM

• Staff: Maria (StaffId = 50)

• Status: Confirmed

• Payment: Pending

Step 4: Service Completion

1. Staff provides service

2. Payment is processed → PaymentStatus = "Paid"

3. BookingStatus = "Completed"

Step 5: Customer Reviews

Customer creates ServiceCompanyBusinessLocationComment:

• Rating: 5 stars

• Comment: "Excellent work!"

• This updates location's average rating

⚠️

Common Issues & Notes

1. Issue in ServiceCompanyBusinessLocationComment

Type Mismatch
// WRONG: public Staff? Customer { get; set; } // SHOULD BE: public Customer? Customer { get; set; }

2. Unused Property

Potentially Unused
public int? ServiceCompanyBusinessLocationBookingId { get; set; } // In ServiceCompanyBusinessLocation - appears unused

3. Good Practice

Best Practice

The models include audit fields (CreatedDate, ModifiedDate, CreatedByStaffId) for tracking who did what and when.

4. Naming Inconsistency

Naming Issue
// Inconsistent casing: public int? CreatedforCompanyId { get; set; } // Should be: public int? CreatedForCompanyId { get; set; }

Summary - What This System Does

Model Purpose
ServiceType Categorize services (Hair, Makeup, etc.)
Service Define specific service offerings
ServiceCompanyBusinessLocation Link services to locations with location-specific pricing
ServiceImage Generic service photos
ServiceCompanyBusinessLocationImage Location-specific service photos
ServiceCompanyBusinessLocationPriceHistory Track price changes over time
ServiceCompanyBusinessLocationBooking Customer reservations
ServiceCompanyBusinessLocationComment Customer reviews and ratings

This is a sophisticated multi-tenant, multi-location service booking platform similar to booking systems used by salons, fitness centers, or service marketplaces.
